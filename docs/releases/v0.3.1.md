# v0.3.1 — K-3 II 톤 selector의 원본 값 전달

selector 5·6이 입력 객체의 두 u16 값을 읽어 내부 설정에 하위 8비트로 기록하는 경로를 공개합니다. 원본 ARM 구간의 5개 사례를 다시 실행했고, 전체 관측과 현재 공개 JSON이 바이트 단위로 일치했습니다. 기본 테스트 101개와 문서 검증이 통과했습니다.

- selector 6의 기본값 0x20 기록, 상위 비트 절삭, 입력 객체 주소 변경을 대조했습니다. 서비스·MMIO·CP15 응답을 만들지 않았으며 실행은 선택된 leaf 구간에 한정됩니다. [분석과 도식](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/tone-selectors.html) · [전체 관측](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/tone-selectors.json)
- 다음 과제는 selector 5의 저장값 복원 호출과 실제 메뉴 이벤트를 연결하고, 설정 관리자에서 촬영 작업으로 전달되는 복사·버퍼 재사용을 확인하는 것입니다. 값의 물리적 의미와 촬영 도달성은 미확정입니다.
- v0.3.0의 재구축·AF·UI 연구를 포함합니다. 수정 펌웨어의 카메라 수용·부팅·복구, 최종 Lightroom 색 재현과 UI 이식은 검증하지 못했습니다. [전체 연구 현황과 다음 과제](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/research-program.html)

ZIP에는 분석 코드와 문서가 들어 있습니다. 원본 펌웨어와 실험용 카메라 설치 이미지는 포함하지 않습니다. 재현 입력은 별도로 준비하며 ZIP의 무결성은 함께 제공하는 SHA256SUMS.txt로 확인할 수 있습니다.
