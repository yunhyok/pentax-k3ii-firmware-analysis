# v0.4.0 — 새 문서 검수와 문장 다듬기

v0.3.x에서 올라온 문서를 검수해 다른 문서와 같은 형식으로 다시 쓰고, 사이트 전체의 문장을 다듬은 릴리스입니다. 새로운 분석 결과는 없습니다.

문서: https://yunhyok.github.io/pentax-k3ii-firmware-analysis/

## 바뀐 것

- **새 문서 8쪽을 다시 썼습니다.** 톤 처리 6쪽(`tone-provenance`, `tone-inputs`, `tone-scale`, `tone-upstream`, `tone-manager`, `tone-selectors`)과 `preserved-continuity`, `register-dma`입니다. 요약과 확인한 범위를 맨 앞에 두고, 배경 설명과 그림을 넣고, 주소·해시는 접어 두었습니다.
- **RAW 노이즈 감소 검토를 사이트 문서로 옮겼습니다.** Markdown 메모였던 내용을 검수해 [`analysis/raw-nr-feasibility.html`](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/raw-nr-feasibility.html)로 만들었습니다. 결론은 그대로입니다. 조사할 출발점을 찾았을 뿐이고, RAW의 노이즈 감소를 끌 수 있다는 근거는 아직 없습니다.
- **안내 문서를 갱신했습니다.** 영상 처리 안내와 촬영 준비 안내의 지도, 현황 표, 읽는 순서에 새 문서를 넣었습니다.
- **모든 문서의 문장을 다듬었습니다.** 한국어 윤문 규칙에 따라 연결어미 뒤 쉼표를 빼고, 긴 문장을 나누고, 에두른 표현을 직접 서술로 바꿨습니다. 수치·주소·코드는 바꾸지 않았고, 고친 문단마다 기계로 확인했습니다.
- **용어집에 새 용어를 넣었습니다.**

모두 42쪽, 그림 109개입니다. 기존 문서의 파일 이름과 주소는 그대로입니다.

## 검수에서 고친 것

수치·주소·해시는 근거와 모두 맞았습니다.

- `preserved-config.html`: 그림이 정적 분석으로 표시하던 "+0xD 마커 재검사"는 연결 실험에서 실행으로 확인한 항목이어서 그렇게 고쳤습니다.
- 노이즈 감소 메모의 사용설명서 링크가 다른 쪽(초점 설정)을 가리키고 있어 고쳤습니다.
- 첫 화면의 "Lightroom 색 비교는 사진 한 장뿐"이라는 낡은 서술을 현재 상태로 바꿨습니다.
- 새 문서에 섞여 있던 "~다"체, 페이지 전용 스타일, PowerShell 전용 명령을 통일했습니다.

전체 목록과 판단이 필요한 항목은 [`docs/audit/2026-11-second-review.md`](https://github.com/yunhyok/pentax-k3ii-firmware-analysis/blob/main/docs/audit/2026-11-second-review.md)에 있습니다.

## Lightroom 색 프로파일은 넣지 않았습니다

이 릴리스에 카메라 색 프로파일은 없습니다. K-3 II용 후보(차트 한 장으로 맞춘 톤 곡선)를 실제 Lightroom에서 재 보니, Adobe가 Lightroom에 넣어 둔 Camera Natural 프로파일이 카메라 JPEG에 더 가까웠습니다(패치 평균 ΔE00 1.786 대 1.620, 따로 찍은 장면에서 4.057 대 3.948). 후보는 미리 정한 허용값 하나도 넘겼습니다. 조명 하나, 다른 펌웨어 버전의 표본으로만 시험했습니다. 자세한 근거는 [Lightroom 색 프로파일 안내](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-lightroom.html)에 있습니다.

## 알아 둘 점

- 검수는 원본 펌웨어 없이 했습니다. 문서가 공개된 근거 JSON·검증기와 맞는지 확인했고, 검증기를 펌웨어에 다시 돌리지는 않았습니다.
- 근거 JSON과 검증기는 고치지 않았습니다.
- 이 저장소에는 여전히 원본 펌웨어, 제조사 코드, 카메라에 넣을 수 있는 펌웨어가 없습니다. 모든 분석은 PC에서 했습니다.

## 내려받기

`pentax-k3ii-firmware-analysis-v0.4.0.zip`에 저장소 전체가 들어 있습니다. 압축을 풀고 `index.html`을 브라우저로 열면 됩니다. `SHA256SUMS.txt`로 파일을 확인할 수 있습니다.
