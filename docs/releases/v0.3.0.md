# v0.3.0 — K-3 II 촬영 경로와 톤 입력 재현

펌웨어 1.12의 촬영 준비, 저장용 인자와 톤 입력을 원본 코드 구간별로 확인한 연구 릴리스입니다. 재현은 PC의 합성 메모리에서 진행했습니다.

## 촬영·보존 레코드와 재구축

- 보존 설정이 마커 소비자로 전달되는 경로와 작업자 매개변수에서 목록 응답으로 이어지는 흐름을 추적했습니다. 일부 저장 경로는 DMA에 넘길 인자를 만들기까지 확인했습니다. 실제 DMA 완료, 버퍼 수명과 저장 뒤 재읽기는 미확인입니다. [정책 플래그](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/preserved-config.html) · [작업자와 목록 응답](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/preserved-continuity.html) · [저장 인자와 DMA](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/storage-dma-analysis.html)
- 재패킹과 일부 함수의 재구현은 오프라인에서 검증했습니다. 수정 이미지의 카메라 수용, 기록, 부팅과 독립 복구는 아직 확인하지 못했습니다. [재구축 안내](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/guide-rebuild.html)

## 톤과 Lightroom

- 두 상위 호출에서 내부 매개변수 48바이트의 선택·복사와 일부 필드의 갱신 순서를 원본 명령으로 확인했습니다. selector 5·6의 선행 값 생산, 실제 촬영 순서와 버퍼 재사용은 미확인입니다. [톤 설정 관리자](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/tone-manager.html)

- 톤 문맥과 곡선 생산자에 전달되는 포인터·정수의 출처를 추적했습니다. 새 상위 입력 일곱 조건과 별도 소비자 네 조건을 원본 명령으로 대조했습니다. 0 분모 사례는 Thumb 처리기의 첫 명령 전에 멈췄습니다. 구성 파일 읽기, 실제 촬영에서의 버퍼 순서와 처리기 본문은 검증 범위 밖입니다. [톤 문맥과 곡선 생산자](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/tone-provenance.html) · [R5 상위 입력과 0 분모](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/tone-upstream.html)
- Lightroom의 별도 실험에서 차트로 정한 톤을 독립 RAW 장면에 적용했습니다. 고정된 영역에서 색차가 줄었지만, 합성 톤 DCP는 사전 최대 색차 기준을 모두 충족하지 못했습니다. 펌웨어 1.12의 여러 조명과 촬영 모드에서 검증한 프로파일은 아직 없습니다. [독립 장면](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/color-scene-transfer.html) · [합성 톤 시험](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/lightroom-composed-tone.html)

## AF와 UI

- 기존 AF 카운터와 보정값 분석은 향후 구동 판단을 조사할 출발점입니다. 위상차·콘트라스트 센서 입력이 원본 상태를 바꾸는 경로와 실제 렌즈 이동은 남아 있습니다. 색공간 설정은 원본 상태 전이와 알림을 비교했으며, K-3 III 화면 이식과 실제 입력·LCD 출력은 검증하지 못했습니다. [AF 카운터와 보정값](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/af-input.html) · [메뉴와 UI 안내](https://yunhyok.github.io/pentax-k3ii-firmware-analysis/analysis/guide-ui.html)
